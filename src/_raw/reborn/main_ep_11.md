## サブセブン聖域 {#subseven-sanctum}

檻に移されます。ここの緑の本を読んでください——というより、このダンジョンで見かける緑の本はすべて読んでください。経文の内容と、末尾の数字を控えておきましょう。

**クレッフィ** が扉を開けたら外へ出ます。リボーンの潜入パートへようこそ。

!img("subseven_mess.png")

上の芸術的傑作において、赤いものが見張りとその視野です。黄色の経路は一部の見張りの移動と視線の変化を、青い線がプレイヤーの通るべき道を示します。こまめに、特に青い点の位置でセーブすることをおすすめします。見つかったら読み込み直したほうが時間の節約になります。高速化もオフにしておくとよいでしょう。

迷路を進む途中、右側の扉に入ります。中では本を読み、*のろいのおふだ* と *聖なるフィールドの資料* を回収してください。

外に戻ったら、頃合いを見て上へ進んで近くの見張りをやり過ごし、行けるようになったら左へ。あまり左へは行けないと気づくはずなので、巡回する見張りをやり過ごすタイミングで下へ進み、通り過ぎたら上、左、下と動いて視界から外れます。ここから、見張りが右へ戻ったら左へ進みますが、行き過ぎないように。

左の施錠された扉の先では、回転する見張りに向かってまっすぐ上へ進む必要がありますが、その姿は全体が見えません。何度かやり直すことになるかもしれませんが、スプライトの脚が前を向いているか後ろを向いているかを見て、上そして左へ進むタイミングを正確に合わせてください。

最上部の階段を上ると見張りは全員いなくなるので、以降は見つかる心配なく自由に動けます。

## 教団とギャングのサイドクエスト {#a-cult-and-a-gang-sidequests}

7番街とその周辺で片付けられるサイドクエストがいくつかあります。まずサブセブン聖域へ戻り、五芒星のものに話しかけてください。*たましいのロウソク* を持っていれば **ヒトモシ** を捕まえられます。

7番街に戻ると、左下の隅の家の鍵が開いています。*かいのカセキ* を持っていて *こうらのカセキ* を持っていない場合、Twitch Plays Pokémon の信者から **カモネギ** を持ってくるよう頼まれます。応じると *ヒレのカセキ* か *アゴのカセキ* を選べます。**アマルス** はすでにいるので前者を選ぶ意味はありません。アゴのほうを選びましょう。

**アマルス** と *アゴのカセキ* の両方が揃ってはいますが、この信者は **ピジョット** と引き換えにもう1つ化石をくれます。以降も *かいのカセキ* を渡せば、*アゴのカセキ* と *ヒレのカセキ* を追加で交換できます。

外に戻り、まだイベントを見ていなければ、心理学者からポケモンの売り手のほうへ南に歩くと、クラウドバリー夫人が怒って去っていくのが見えます。自分のギャングの頭から彼女の家に集まるよう言われるので、ラピス区へ出てください。

外にいるついでに触れておくと、ロドクラインのトーテムで **リグレー** と **ヤジロン** を入手済みなら、**ゴビット** を取りに行けます（他の2通りの場合は、キタエ・アストラエで **リグレー** と **ヤジロン** を普通に捕まえられます）。必要なら済ませておきましょう。

ラピスのクラウドバリー夫人の家へ向かいます。

!battle(["Craudburry", :HARRIDAN, 0])

これが普通のポケモンなら、他と比べてかなり厳しい戦いになったでしょう。しかしここはポケモンリボーンです。彼女の編成には噛み合いすらありません。フィールドも天候も何もなし。ただ努力値調整された、面倒ではあるが倒せる5匹がいるだけです。

## イオリア渓谷 {#iolia-valley}

バンハネン迷宮へ向かいます。右上の大きな木の裏にイオリア渓谷への入口が隠れています。赤い宝石に話しかけると、いわくだき用の壁ができます。その道を進んでください。

!enc(333, ["Grass", "Fishing"], ["Old", "Good"])

最初のエリアでは隠された *ハイパーボール*、*ねむけざまし*、*あおいかけら* が見つかります。左下でもう一度赤いカギを使っていわくだき用の壁を作り、できた洞窟に入ります。

!enc(340, nil, nil, "Iolia Valley Caves")

下から出ます。次のエリアでは隠された *むらさきのかけら* を拾い、新しい洞窟の入口を作ります。最後に隠された *みどりのかけら* を拾い、*緑のクリスタルのカギ* を回収してください。

渓谷の入口までずっと戻ります。2段目に光る緑の水晶が見えるので、起動すると生け垣がいわくだき用の宝石に変わります。これを砕くと *みどりのかけら* が出ることがあります。

そこから下へ進み、赤いカギで新しい扉を開けます。洞窟の先では隠された *あかいかけら* と *青いクリスタルのカギ* が手に入ります。

もう一度渓谷の入口へ戻ります。水辺の光る青い水晶に話しかけて起動すると、氷の橋ができます。

水の対岸ではまず上へ進み、カギを使いながら道をたどります。途中で隠された *むらさきのかけら* と *あおいかけら* が見つかります。突き当たりの緑の水晶を起動したら、氷の橋へ戻って下へ。この道沿いで隠された *みどりのかけら* と *マジカルシード* を拾ってください。新しく作った洞窟の入口に入ると、ベネットが立ちはだかります。

**好感度の選択肢**:
- ベネットに「やるべきことをやらせる」と伝える (+1 ベネット)
- ベネットに「やるべきことをやらせない」と伝える (-1 ベネット)

*紫のクリスタルのカギ* を回収します。近くの紫の水晶に話しかけると洞窟が変化します。新しい出口の外では、隠された *シナモンキャンディ* と *スペシャルアップ* が手に入ります。次の赤い洞窟では、水晶を使ってもう1つ洞窟を変化させます。一番北の氷の橋までずっと戻りましょう。

そこから上そして右へ進み、洞窟に入ります。紫の水晶でこの洞窟を変化させ、新しい出口から出てください。隠された赤いかけらを拾い、上の赤い洞窟に入ります。中で *ダークメモリ* と *暗黒クリスタルのどうくつの資料* を回収します。手持ちに *あくのはどう* か *ナイトバースト* を覚えているポケモンがいれば、ここでもう1つできることがあります。野生戦でそれを使ってクリスタルのどうくつを暗黒クリスタルのどうくつに変えると、**ヤミラミ** が手に入ります。前者はもうすぐわざマシンで手に入るので、後回しにしても構いません。

!enc(507, nil, nil, "Iolia Valley Northeast Dark Cave")

外に戻り、もう一度渓谷の入口へ向かいます。2段目の洞窟に入り、紫の水晶を起動して変化させます。外へ出て、左から1段目の洞窟に入り、新しくできた出口から出てください。*やみのいし* と、隠された *チーゴのみ* が手に入ります。

先へ進むには、入口へ戻って、2段目から今変化させた洞窟を元に戻し、1段目の洞窟をもう一度通ります。この道をたどると *光のかけら* があるので、赤い洞窟の入口をもう1つ作って中へ入ってください。

!battle(["Bennett", :BENNETT, 1], "Dark Crystal Cavern")

気の毒に、**メラルバ** をもう1レベル上げて **ウルガモス** にすることすらできなかったようです。それでも今いるフィールドの恩恵は受けており、今回は *シグナルビーム* の強化という形で現れます。相変わらずむしポケモンは打たれ弱く、突ける弱点も多いので、いわ技とほのお技で倒せます。

**好感度の選択肢**:
- 1回目でベネットに勝つ (+1 ルナ、-2 ベネット)

## ばくはつのこなとクリスタルのカギでの収穫 {#blast-powder-and-crystal-key-goodies}

これでルナに挑めます。とはいえ *ばくはつのこな* とクリスタルのカギが揃った今、できることがいくつかあります。すぐ戦いたい場合は読み飛ばしてください。

ルナの部屋には紫のワープができているはずで、イオリア渓谷の入口へ飛べます。便利です。

イオリア渓谷を出て、南アベンチュリンの森を抜けてタンザン山へ向かいます。行けるようになったら右へ進み、以前サファイラが飛び出してきた部屋に入ってください。緑のカギで新しい道を開けられます。

!img("tanzan_east.png")

見えにくい段差をいくつか飛び越えて洞窟の岩肌に乗り、下そして右へ進みます。クリソリア峠へ出ましょう。

南へ進みながら隠された *すごいキズぐすり* と *ノーマルジュエル* を拾います。次の2部屋では岩をどけて *あなぬけのヒモ* を回収してください。大きな部屋はやや難しく、行き詰まらないように岩を慎重に動かしながら、3つのタンクすべてに触れて赤にする必要があります。詰まったら部屋を出れば元に戻せます。筆者が解いたときの配置は次のとおりです。

!img("wasteland_wall_boulders.png")

成功したら、新しく開いた扉から出ます。近くのはしごを下りてください。次のパズルは、岩を穴に落として石を砕きつつ、はしごを上っていくものです。上るには、エリア左側のはしごを使います。

パズルを解く手順はおおよそ次のようになります。

- 左の最初のはしごを下りる
- 右へ進んで穴に落ちる
- この岩を右端まで押して穴に落とし、自分も飛び降りる
- 岩を右へ押し、このはしごを上る
- 右手のはしごを上る
- 岩を左へ押して穴に落とし、自分も続く
- 左の岩は無視して、右へ進んで穴に飛び込む
- 左へ進んで次の穴へ。はしごの位置に「復帰」する
- 右へ進み、穴に2回飛び込む
- 右のはしごを上る
- この岩を右端まで押して穴に落とし、自分も続く
- 岩をはしごの右側へ押し、3回上る

このパズルを終えて壁の上に出たら、左へ進んで *反転フィールドの資料* を回収します。そこから右手、タンクの裏に隠し洞窟の入口があります。中では *どくどくだま* と *ユレユのカギ* が手に入ります。ここのタンクに話しかけると **ダダリン** とも戦えます。タンザン山へ出ましょう……来た道をすべて戻ることになります。

近くにいるついでに、スピネルタウンへ向かいます。先ほど手に入れた *アゴのカセキ* を復元すると **チゴラス** が手に入ります。

次の2つは、かかる手間に対して報酬の価値が非常に低いのですが……網羅のため一応やっておきます。最初の目的地はビクスビジョン荒地です。坑道を使い、かつてミスター・ビグルスワースと戦った部屋までずっと戻ってください。*ばくはつのこな* を使うと *めざめいし* が手に入ります。

2つ目は、アポフィルビーチ行きの船に乗ってアポフィルどうくつに入ります。左側でこなを使うと、隠された *げんきのかたまり* が手に入ります。

これらが済んだら、ベリルのアンダールートへ向かいます。エリア右側に緑の水晶があるので起動してください。ここで揺れる木をいくつか切ると、*デンリュウナイト* に加えて *みどりのプレート* と **キバゴ** のタマゴが手に入ります。素晴らしい。

かつてシェイドと戦ったユレユの廃発電所へ向かいます。右へ進んで上へ回り込み、*ユレユのカギ* を使うと *じしゃく* と *ゴーストZ* が手に入ります。素晴らしい。次に工場の反対側へ回り、またユレユのカギを使って中に入ります。

!enc(281, nil, nil, "Yureyu Power Plant Backroom")

この部屋のモンスターボールはすべて **マルマイン** です。全部倒してから最上部のモニターに話しかけると、**ロトム** とのバトルになります。

ベリル周辺にいるついでに、ベリル墓地へ向かいます。タンザンメテオ基地でサイモンに話しかけていれば、ここに彼がいます。話しかけると彼のサイドクエストが進みます。そのあとペリドット区のショップの右隣の建物へ行き、もう一度話しかけてください。このクエストで今できるのはここまでです。

## エクリプスバッジ {#eclipse-badge}

イオリア渓谷へ戻り、ワープでルナの部屋へ向かいます。

!battle(["Luna", :LUNA, 0], "Dark Crystal Cavern")

リボーンのあくタイプのジムリーダーとの一戦です。攻撃面では、フィールドが *あくのはどう* と *つじぎり* の威力を1.5倍にします。それ以上に重要なのは、あくタイプの防御面も1.5倍になることです。**キリキザン**、**バンギラス**、**アブソル**、**マニューラ**、**ドンカラス** に対して普通なら確実に取れる抜群の一撃が、そう確実ではなくなります。ただでさえ非常に硬い **ブラッキー** への影響は言うまでもなく、*つきのひかり* で最大HPの75%を回復し、回避率まで上げてきます。しかも全員が理想個体かつ努力値調整済みで、これは以降のボス戦でも続く特徴です。ともあれ、フィールドの攻守の強化をうまく使った、素直ではありますが厳しい一戦です。

朗報として、この時点なら対処法は数多くあります。*暗黒クリスタルのどうくつ* のまま戦うなら、あられなしで *オーロラベール* を使えますし、こちらもあくタイプを使えば防御強化を得られます。*マジカルシャイン* と *シグナルビーム* はこのフィールドで強化されるので、これらを使えば相手の防御強化を実質打ち消せます。ドンカラスさえ捌ければ、こうげきの高いかくとうタイプとむしタイプも、耐久上昇を差し引いてなお通用します。相手の編成に特殊技が1つしかない点を突いて、ぼうぎょの高い編成で殴り合う手もあります。

フィールドを変える利点もあります。まず、日照を張るだけで *クリスタルのどうくつ* に変わり、より中立的なフィールドになるため、望むならドラゴン技も効果的に使えます。特筆すべきは *しぜんのちから* で、このフィールドでは *パワージェム* に変わり、*ふいうち* を持つドンカラスへの完璧な回答になります。あるいは *じしん* 系の技で *どうくつ* に切り替えれば、相手の耐久を迂回しつつ、いわ技を強化できます。半減できるのはキリキザンだけです。*じしん* 系の技、強化されたいわ技、強化された *ハイパーボイス* と *ばくおんぱ* と、どうくつには強力な選択肢が揃っています。いずれの場合もバンギラスは脅威のままですが、強力なかくとう技で落とせます。

勝利すると *エクリプスバッジ* が手に入り、上限が Lv.70 に上がります。奇しくも、普通のポケモンならそろそろ終わっている頃合いです。加えて *わざマシン97 あくのはどう* ももらえます。ありがたい。

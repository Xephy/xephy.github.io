# このサイトについて

**ポケモンリボーン 日本語攻略**（<https://xephy.github.io/>）は、PC 向けのファンゲーム
**『ポケモンリボーン』**（Pokémon Reborn）を日本語で遊ぶための攻略サイトです。

日本語で読める Reborn の攻略はほとんど無く、英語の攻略を辞書を引きながら読むか、
手探りで進めるしかありませんでした。このサイトは、**ゲームを日本語化するパッチと、
その日本語で書かれた攻略を、同じ訳語でひとそろいにする**ことを目的にしています。

## 運営者

**Xephy**（<https://github.com/Xephy>）が個人で運営しています。

**『ポケモンリボーン』日本語化パッチ**（<https://github.com/Xephy/reborn-19.5.43-ja>）を
制作している本人です。ゲーム内テキスト 82,524 / 82,619 行（99.9%）を翻訳したもので、
導入方法は<a href="/patch/">日本語化パッチの導入方法</a>にまとめてあります。

このサイトの訳語は、そのパッチの辞書からそのまま書き出しています。**パッチを当てた
ゲーム画面と、この攻略に出てくるポケモン名・わざ名・どうぐ名・地名が1文字も食い違わない**
ように作ってあり、画面と攻略を並べて読み進められます。他の日本語資料と表記が違う場合は、
ゲームの画面のほうに合わせています。

## 攻略本文の出典

エピソードごとの攻略本文は、**BIGJRA 氏**の英語攻略
**<a href="https://bigjra.github.io/">BIGJRA's Walkthroughs</a>** を翻訳させていただいたものです。
本編19話・クリア後9話の進行手順と、本文中のスクリーンショットは同氏の成果によります。

翻訳にあたっては、固有名詞をすべて上記のパッチの訳語に置き換え、日本語で読んで
意味の通る文章に組み直しています。また、原文の画像に英語が焼き込まれていて
日本語では読めなかったもの（**サファイラの会話フローチャート**と
**VRパズルの解答表**）は、日本語で描き直しました。

原典には Pokémon Rejuvenation と Pokémon Desolation の攻略もありますが、
こちらは翻訳しておらず掲載していません。英語版は上のリンクから読めます。

大きく違い、**本家の攻略情報をそのまま当てはめると誤りになります。** そのため数値は
一般的なポケモン攻略サイトから引き写さず、すべてゲーム本体のデータから起こしています。

### 作り方

これらのページは、ゲームのスクリプトを読み取って HTML を書き出す自作のスクリプト
（<a href="https://github.com/Xephy/xephy.github.io">リポジトリ</a>で公開しています）で
生成しています。ゲーム側が更新されたら作り直せるようにしてあり、数値の写し間違いが
起きないようにするためです。

数値の解釈や説明文、どの情報をどう並べるかは人手で決めており、
たとえばわざの説明には、ゲーム内の短い説明文には出てこない**急所率・追加効果の確率・
能力変化の段階**を、コードから読み取って添えています。

更新の履歴は<a href="/reborn/changelog/">更新履歴</a>にあります。

# ポケモンリボーン 日本語攻略

『ポケモンリボーン』を100%クリアするための攻略サイトです。隠しアイテムを含む全アイテム、入手できるポケモン、トレーナーの手持ちと対策、ショップや技教え人の情報、サイドクエストの手順まで、必要なことを一通りまとめてあります。

ゲーム内の固有名詞（ポケモン名・わざ・どうぐ・地名など）は、<a href="/patch/">日本語化パッチ</a>と同じ対訳を使っています。パッチを当てた状態のゲーム画面と、そのまま読み比べながら進められます。

ゲーム本体をまだ日本語化していない場合は、<a href="/patch/">日本語化パッチの導入方法</a>からどうぞ。

## このサイトについて

**ポケモンリボーン 日本語攻略**（<https://xephy.github.io/>）は、PC 向けのファンゲーム
**『ポケモンリボーン』**（Pokémon Reborn）を日本語で遊ぶための攻略サイトです。

日本語で読める Reborn の攻略はほとんど無く、英語の攻略を辞書を引きながら読むか、
手探りで進めるしかありませんでした。このサイトは、**ゲームを日本語化するパッチと、
その日本語で書かれた攻略を、同じ訳語でひとそろいにする**ことを目的にしています。

くわしくは<a href="/about/">このサイトについて</a>をご覧ください。

# ポケモンリボーン 日本語攻略

『ポケモンリボーン』を100%クリアするための攻略サイトです。隠しアイテムを含む全アイテム、入手できるポケモン、トレーナーの手持ちと対策、ショップや技教え人の情報、サイドクエストの手順まで、必要なことを一通りまとめてあります。

ゲーム内の固有名詞（ポケモン名・わざ・どうぐ・地名など）は、<a href="/patch/">日本語化パッチ</a>と同じ対訳を使っています。パッチを当てた状態のゲーム画面と、そのまま読み比べながら進められます。

ゲーム本体をまだ日本語化していない場合は、<a href="/patch/">日本語化パッチの導入方法</a>からどうぞ。

## このサイトについて

運営しているのは、<a href="/patch/">『ポケモンリボーン』日本語化パッチ</a>を作っている Xephy です。**ゲームを日本語にするパッチと、その日本語で読める攻略を、同じ訳語でひとそろいにする**ために作っています。ポケモン名・わざ名・どうぐ名・地名は、パッチを当てたゲーム画面とこのサイトで1文字も食い違いません。

図鑑807種・わざ691件・出現場所・種族値ランキング・進化条件・わざマシン・フィールド効果は、**『ポケモンリボーン』本体のデータから直接起こしたもの**です。本作は本家シリーズと種族値も出現場所も進化条件も違うため、本家の攻略情報をそのまま当てはめると誤りになります。

エピソードごとの攻略本文は、<a href="https://bigjra.github.io/">BIGJRA's Walkthroughs</a>（BIGJRA 氏）の英語攻略を翻訳させていただいたものです。英語が焼き込まれていて読めなかった図（サファイラの会話フローチャート、VRパズルの解答表）は日本語で描き直しました。原典には Pokémon Rejuvenation と Desolation の攻略もありますが、こちらは翻訳しておらず掲載していません。

くわしくは<a href="/about/">このサイトについて</a>をご覧ください。有志による非公式のファンサイトで、任天堂・株式会社ポケモン・ゲームフリーク・クリーチャーズおよび Reborn 開発チームとは関係ありません。

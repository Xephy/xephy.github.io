# 手で決めた値の根拠

- S479 City Restore: 15章の最後で ON。本文16章の冒頭「大テントの外へ出ます。リボーンシティ…へ飛ぶ前に」から
  ネオ地区 (metatext の :Switches [[:Reborn_City_Restore, true]]) の話になる。E15=37 のセーブでは OFF。
- S1305 Postgame Active / S1718 Marshadow Academy / V562 Cresselia / V627 Meloetta: クリア後や伝説の依頼で立つもの。本編の章では立てない。
- S171 Factory Gate: ブラックスチーム工場1階の正面ゲートの解錠。本文6章「ブラックスチーム工場」。6章から ON。
- S174〜S177 Pyrous: パイロス山の溶岩の通り道。E6 を 17 にする工場のイベントで初期化され、6章の仕掛けで決まる。
  6章以降は14章のセーブと同じ (S174 ON、S175〜177 OFF)。
- S194/S195 Grotto Reactor: ビクスビジョン洞穴の仕掛け (本文7章)。7章から ON (14章のセーブも ON)。
- S291 Riding Tauros: ケンタロスに乗っている間だけ ON。章の終わりでは OFF。
- S423 Labyrinth Meteors: 11章の途中でバンハネン城のイベントが ON、同じ11章のギャングのイベント (E11 を書く) で OFF。
  章の終わりでは OFF (14章のセーブも OFF)。
- S652 Railnet Rebuilt: 17章「リボーン復興プロジェクト」のアイビーライン駅の場面 (S1969 が条件) で ON。
- S653 Slums Rebuilt: 大ホールの寄付による再建だけが立てる。寄付は任意なので立てない。
- S972 Rail Train Derailed: 地下鉄道網の列車のシャルロットの場面。これが開く先 (クリソリア・タンザン方面) は本文8章。8章から ON。
- V145 Chrysolia Forest: クリソリアの森の仕掛け (8章)。8章以降は14章のセーブの値 2。
- V156 Scraggy: スラムの遊び場の依頼。14章のセーブで 0 (未了) なので、どの章も 0。
- V162/V165 IoliaRed: イオリア渓谷のクリスタルの仕掛け (11章「クリスタルのカギでの収穫」)。11章以降は14章のセーブの値 3。
- V74 Apartment Elevator: エレベーターの行き先。乗った人が切り替える値なので、どの章も14章のセーブの値のまま。
- 道が行き止まりの部屋にしか効かない37個は、14章より前は「まだ済ませていない」(初期値)、14章からはセーブの値にしている。

# ナビの進み具合 (states/)

ナビ (/reborn/navi/) は、章ごとの進み具合で通れる道を探す。`states/ch<章>.json` がその進み具合。
`bin/navi-build ch<章>` がこれを読んで道を探す。

## 14章

14章を終えた直後のセーブデータ (15章の物語変数がまだ0のもの) から、`bin/navi-state` で書き出した。
道探しに使うもの (スイッチ・変数・セルフスイッチ・バッジの数・連れ歩きの有無・条件分岐で
調べられる大事なもの) だけで、名前や手持ちは含まない。

## ほかの章

セーブが無いので、14章のセーブを軸に、ゲームのデータから組み立てた。

- **物語変数** (E2 Story〜E19 Story): その章までは最後の値、それより後は0。最後の値は、14章までは
  セーブの値、15章以降はデータの中の代入と条件の最大値 (14章までの値で、この求め方がセーブと
  一致することを確かめた)。
- **バッジの数**: バッジを渡すイベント (`$Trainer.badges[n] = true`) が書く物語変数から、章ごとに決めた。
  1章1個 … 14章12個 … 19章18個。
- **スイッチ・変数・セルフスイッチ**: それを書き換えるイベントに「何章の出来事か」の見積もりをつけ、
  規則で決めた。
  - そのページで物語変数 E<k> を書く → k 章
  - 条件に E<k> や、立つ章の分かっているスイッチがある → その章以降
  - 地図が攻略本文に初めて出てくる章 → その章以降
- **大事なもの**: 攻略本文に初めて出てくる章から持っているものとした。

規則で決まらない値のうち、**行ける範囲を変えるもの**だけを1つずつ根拠を調べて決めた
(`decisions.md`)。行き止まりの部屋にしか効かないものは、14章より前は「まだ済ませていない」、
14章からはセーブの値にしている。

## 確かめたこと

- 各章の状態で、その章の本文の見出しに出てくる場所へ大ホールの前 (16章からはネオオパール区) から
  歩いて行けること。例外は19章のラブラドラシティとチャンピオンロードで、本文では「カルセノンシティの
  ハーディに話しかけて」向かう場所。19章を終えた状態では、歩いて行ける道が見つからない。
- 道はどの章も、切り替わる値を持ち歩いてもう一度たどり、通れるものだけを載せている。
